## 2. How to Run

### A. Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) 24.19.0
- [npm](https://www.npmjs.com/) 12.0.2
- [Git](https://git-scm.com/) 2.39.5

Verify the installed versions:

```bash
node --version
npm --version
git --version
```

### B. Installation

Clone the repository:

```bash
git clone https://github.com/mj-muhajirin/aviosit-personal-website-sample
```

Go to the repository:

```bash
cd aviosit-personal-website-sample
```

Install the project dependencies:

```bash
npm ci
```

> `npm ci` installs the exact dependency versions defined in `package-lock.json`.

### C. Run

Start the development server:

```bash
npm run dev
```

The application will be available at: http://localhost:4321
